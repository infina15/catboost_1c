# catboost_1c
Пример использования Yandex CatBoost и MyStem для классификации коротких текстовых сообщений

Не является полноценным решением

Для работы необходимо создать справочник КлассификацияТекста с реквизитами:
- ПутьФайлаМоделиОбучения
- ПроцентТеста - по умолчанию 20
- СтопСлова - список стоп-слов по одному на каждой строке. Например "и", "а", "но", "пожалуйста", "привет" и прочие, которые будут шуметь в обучении
- КоличествоПоследнегоОбучения - количество сообщений, на которых было проведено последнее обучение. Для статистики.

Так же необходимо добавить справочник "КлассификацияТекста_Категории" для указания категорий.

В функции ПолучитьНаборыДанныхОбучения необходимо дописать запрос получения сообщений по примеру функции "ТекстЗапросаЧатаСообщенийЛН".

Функцию "ОбучитьМодель" можно вызывать из регламентного задания. Например раз в неделю.

Функцию "ПолучитьКатегориюСообщений" можно вызывать для определения класса сообщения.
